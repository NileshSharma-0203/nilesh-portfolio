# Nilesh Sharma — Portfolio

A modern developer portfolio built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Framer Motion** focused on systems engineering, backend infrastructure, AI tooling, cybersecurity, and low-level programming.

Designed with a cinematic dark UI inspired by modern developer tools, operating systems, and cyberpunk aesthetics.

---

## Overview

This portfolio showcases:

* Systems programming projects
* Backend & infrastructure engineering
* AI runtime experimentation
* Networking & security projects
* Technical writing
* Interactive UI/UX engineering

The goal of this project was not just to create a personal website, but to build a highly polished, performant, and immersive engineering-focused experience.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
